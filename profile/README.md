## 🏢 회사 소개

㈜티유정보기술은 리조트, 호텔, 워터파크, 골프장 등 레저 산업을 위한 
통합 IT 솔루션을 개발·공급하는 전문 기업입니다.

## 💼 주요 사업 영역

- 🏨 **호텔/리조트 PMS** — 객실 관리, 예약 시스템
- ⛳ **골프장 운영 시스템** — 티오프·캐디 최적화, 회원 관리
- 🎢 **워터파크 솔루션** — 발권, 락커, 매점 통합 관리
- 📊 **통합 레저 시스템** — 다중 시설 통합 운영

## 🤝 주요 고객사

- 호반호텔앤리조트
- 외 다수 레저·호스피탈리티 기업

## 🛠 기술 스택

**Backend**
- Java (Spring Boot, eGovFrame)
- PL/SQL, PostgreSQL, Oracle

**Frontend**
- JSP, React
- HTML5 / CSS3 / JavaScript

**Infrastructure**
- Apache, Windows Server, Ubuntu
